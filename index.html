HELP CENTER

Frequently asked questions

What do I send to the recipient?

Send the encrypted binary string or downloaded .hfx packet, then share the one-time key through a separate trusted channel.

Can I send the key in the same email?

You can, but anyone who gets both the packet and key can read the message. The Gmail draft intentionally includes only the encrypted packet.

Can I encrypt any file type?

Yes. Files up to 10 MB are encrypted intact. Short TXT, Markdown, and CSV files can instead be loaded as text and Huffman encoded. The recipient loads the encrypted packet file, enters the key, and saves the restored original.

Can the receiver open any file extension?

Yes—the packet picker accepts any extension. Its contents still need to be a valid encrypted HFX packet. After unlocking it, the recipient can save the restored DOCX, PDF, image, or other original file.

Does “Open Gmail” send the message?

No. It opens a draft in Gmail for you to review and send. A website would need Google sign-in authorization to send email directly.

What if someone changes the packet?

AES-GCM checks the packet's authentication tag. If the packet or key is wrong, decryption fails instead of showing altered text.
